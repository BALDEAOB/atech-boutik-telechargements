# ATECH Boutik

Téléchargements officiels de l'application **ATECH Boutik** (gestion de boutique : ventes, stock, caisse, crédits clients).

- Éditeur : **ATECH-AOB**
- Site : https://atech-aob.com

Les fichiers d'installation se trouvent dans la page **Releases** de ce dépôt :

| Appareil | Fichier |
|---|---|
| Téléphone Android récent | `ATECH-Boutik-Android.apk` |
| Ancien téléphone Android (32 bits) | `ATECH-Boutik-Android-32bits.apk` |
| Ordinateur Windows | `ATECH-Boutik-Windows.exe` |

Ce dépôt ne contient aucun code.
